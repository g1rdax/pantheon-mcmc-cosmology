# Оцінювання космологічних параметрів розширеної моделі Всесвіту (Pantheon+SH0ES)

Високопродуктивний обчислювальний конвеєр на Python, розроблений для дослідження проблеми **Хабблівської напруги** (Hubble Tension). Проєкт реалізує як стандартну модель Flat **ΛCDM**, так і розширену космологічну модель **w₀w_aCDM** з динамічною темною енергією (параметризація CPL). Розрахунки базуються на повному каталозі спостережень Pantheon+SH0ES (1701 крива блиску наднових типу Ia) та повній матриці коваріації розмірністю 1657 × 1657 зі збереженням структури STAT+SYS.

Науково-дослідницький проєкт розроблено для **Малої академії наук України (МАН)**.

---

## 🌌 Математична обробка та космологічний аналіз

Програма виконує спільне прецизійне оцінювання космологічних констант за допомогою ансамблевого інваріантного до розтягування MCMC-семплера `emcee`.

*   **Інтеграція калібрувальної драбини відстаней:**
    Для спільного фіту використовуються стандартизована видима величина `m_b_corr`, абсолютна величина наднових M_B, незалежні відстані цефеїд `CEPH_DIST` та бінарний прапорець `IS_CALIBRATOR`. Модель обчислює експериментальний модуль відстані за формулою: `mu = m_b_corr - M_B`. Для цефеїдних калібраторів залишок розраховується як різниця між отриманим модулем та прямою відстанню цефеїд. Для об'єктів космологічного потоку залишок порівнюється з теоретичною кривою розширення Фрідмана. Такий підхід повністю розриває виродження між параметрами M_B та H₀, дозволяючи цефеїдним якорям безпосередньо фіксувати нуль-пункт кривої. Стовпець `MU_SH0ES` є похідним і не бере участі у розрахунках.

*   **Офіційне космологічне маскування даних:**
    Скрипт зчитує всі 1701 рядок релізу та повну матрицю коваріації 1701 × 1701. Програма автоматично відтворює офіційну схему відбору Pantheon+: об'єкти беруться в аналіз лише якщо червоне зміщення zHD > 0.01 або якщо об'єкт позначено як цефеїдний калібратор (`IS_CALIBRATOR == 1`). Відповідна підматриця коваріації вирізається за допомогою індексації NumPy (`np.ix_`), суворо зберігаючи вихідний порядок рядків. Повтори об'єктів за Candidate ID (`CID`) зберігаються для точного обліку міжобзорових систематичних кореляцій.

*   **Матрична алгебра та функція правдоподібності:**
    Стовпці діагональних похибок (`m_b_corr_err_DIAG` та `MU_SH0ES_ERR_DIAG`) використовуються виключно для графічної візуалізації «вусів» на рисунках. Функція гаусового правдоподіб'я обробляє **повну матрицю коваріації**, що враховує всі міжобзорові систематичні зв'язки та калібрувальні невизначеності. Для оптимізації розрахунку квадратичної форми мінімізації Хі-квадрат (chi²) замість повільного прямого обертання великої матриці реалізовано швидке декомпозицію Холецького (`scipy.linalg.cho_factor`).

*   **Розпаралелювання та векторизоване інтегрування:**
    Для обчислення сопоставимої відстані рівнянь Фрідмана на кожному MCMC-кроці застосовано векторизовану квадратуру Гаусса—Лежандра за 64 опорними вузлами. Обчислення виконуються паралельно для всього масиву даних за допомогою матричного розширення осей NumPy, що виключає повільні цикли мови Python. Код підтримує багатопоточне розпаралелювання (Multiprocessing CPU Pool) з ізольованим контекстом `spawn` для стабільної роботи на Windows та Unix-архітектурах.

## 🚀 Встановлення

Для запуска обчислювального комплексу потрібен **Python 3.10** або новіший. Виконайте наступні команди у вашому терміналі (PowerShell) з каталогу проєкту:

```powershell
# 1. Створення та активація ізольованого віртуального оточення
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 2. Оновлення пакетного менеджера та встановлення бібліотек аналізу даних
python -m pip install --upgrade pip
python -m pip install numpy pandas scipy emcee corner matplotlib
```

## 🏃 Запуск

1. Переконайтеся, що офіційний архів даних `DataRelease-main.zip` розпакований у корінь каталогу проєкту. Програма автоматично сканує відносний шлях: `DataRelease-main/Pantheon+_Data/4_DISTANCES_AND_COVAR/`.
2. Запустіть конвеєр обчислень прямо з кореня папки:

```powershell
# Запуск стандартної моделі LCDM (w0=-1, wa=0 зафіксовані)
python pantheon_mcmc_H0+PLANCK.py --model lcdm --steps 5000

# Запуск розширеної моделі w0waCDM (всі 5 космологічних параметрів вільні для фіту)
python pantheon_mcmc_H0+PLANCK.py --model w0wacdm --steps 5000
```

### Основні CLI-аргументи:
*   `--model`: Вибір космологічного сценарію (`lcdm` або `w0wacdm`).
*   `--steps`: Кількість продукційних кроків MCMC на одного спостерігача (рекомендовано від 3000 до 5000).
*   `--walkers`: Кількість незалежних марківських спостерігачів (ансамблю), за замовчуванням `32`.
*   `--data` / `--covariance`: Явне передавання шляхів до файлів, якщо вони лежать в іншому каталозі.

## 📊 Результати та звітність

Скрипт автоматично генерує та зберігає у робочу папку наступні файли (із суфіксом обраної моделі):

1. `pantheon_hubble_diagram_[model].png` — Публікаційна діаграма Габбла кривої відстаней на верхній панелі та розподіл залишків підгонки на нижній панелі.
2. `pantheon_confidence_contours_[model].png` — Багатовимірний кутовий графік (`corner plot`) з відображенням маргіналізованих одновимірних розподілів параметрів та контурів довірчих інтервалів (68% та 95% рівні).
3. `pantheon_posterior_samples_[model].npz` — Спресований архів масивів NumPy, що містить повні плоскі ланцюги апостеріорних вибірок для аналізу.
4. `pantheon_mcmc_summary_[model].json` — Структурований звіт високої точності: медіани, квантилі, точка найвищої ймовірності (MAP), мінімальний знайдений $\chi^2$, ступені свободи (`dof`) та приведений $\chi^2_{\mathrm{red}}$.

### Апріорні межі (Flat Priors):

* $50.0 \lt H_0 \lt 90.0 \ \text{km/s/Mpc}$
* $0.0 \lt \Omega_m \lt 1.0$
* $-3.0 \lt w_0 \lt 1.0$ (тільки для `w0wacdm`)
* $-3.0 \lt w_a \lt 3.0$ (тільки для `w0wacdm`)
* $-20.5 \lt M_B \lt -18.0 \ \text{mag}$
